# Project 11 - Infrastructure Changes with Branching Policy

## Overview

This project demonstrates the implementation of a branching strategy for Infrastructure as Code (IaC) using Git and GitHub.

## Objectives

- Create a feature branch
- Implement Terraform infrastructure changes
- Submit changes through a Pull Request
- Merge approved changes into the main branch

## Technologies

- Terraform
- Git
- GitHub

## Outcome

Successfully demonstrated an infrastructure change workflow using feature branches and Pull Requests.
